## How to update the website later

### On this computer (Cursor)

1. Open the project folder in Cursor.  
2. Edit text, prices, photos, or ask Cursor Agent to help.  
3. Save your changes.  
4. Upload to GitHub (commit + push) so the live site updates.  
5. After a minute or two, refresh:  
   https://rachelm1974.github.io/rachel-mimran-portfolio/

### On another laptop

1. Sign in to GitHub as **Rachelm1974**.  
2. Open: https://github.com/Rachelm1974/rachel-mimran-portfolio  
3. Click **Code** → **Download ZIP**, or clone the repo.  
4. Open the folder in Cursor and continue editing.  
5. Push changes back to GitHub so the live site updates.

---

## Adding a new photo

1. Put the photo in the project folder (prefer a simple English filename, e.g. `lemon-tart.jpg`).  
2. Add it in `index.html` (portfolio and/or menu).  
3. Push to GitHub.  
4. Check the live site.
